# Third-party notices

The frontend ships the third-party fonts, icons, glyphs, trademarks and runtime libraries
listed below. Each keeps its own license. Everything else in `src/assets/` is project
artwork.

## Project artwork

The illustrations, avatars and mascots in `src/assets/` were made by the team for this
project in `ui-design/ui.pen`, with the AI-assisted generation of the pen.dev design tool,
and exported as SVG. The default avatar served by User Service is generated by its own code.
The third-party glyphs inside two of these files are listed under "Icons and glyphs" below.
